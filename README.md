# 🌐 Sreejesh Mohan - Portfolio Website

Welcome to my personal portfolio website! This project serves as a premium showcase of my multifaceted skills spanning frontend development, UI/UX design, and cinematic video editing. Built completely from scratch with HTML, CSS, and vanilla JavaScript, it demonstrates a deep understanding of modern web design, responsive grids, and interactive user experiences.

---

## 📋 Sections & Navigation

- **Home**: Dynamic landing page featuring a typing animation, bio, and quick access to social profiles and resume.
- **Skills**: A modern, asymmetrical "Bento Box" editorial layout showcasing technical proficiencies across frontend, backend, design, and AI workflows.
- **Experience**: Timeline detailing my professional journey, blending creative design and software testing.
- **My Projects**: A premium 2x2 responsive grid showcasing full-stack web applications with hovering glow effects and technology badges.
- **UI/UX Designs**: A 3-column showcase of high-fidelity interface designs with direct links to case studies.
- **Video & Motion**: A cinematic showreel layout highlighting beat-synced edits, color grading, and motion graphics with inline video playback.
- **Contact**: A glassmorphic contact form featuring JavaScript-based validation and animated input fields.
- **Resume**: Downloadable PDF and an interactive modal for in-browser viewing.

---

## 🚀 Key Features & Upgrades

- **Premium UI Aesthetics**: Deep navy cinematic theme with cyan/blue accents and glassmorphic (backdrop-filter) elements.
- **Modern CSS Grid/Flexbox**: Extensive use of CSS Grid for complex, responsive layouts (Bento boxes, 2-col and 3-col project galleries).
- **Interactive Animations**: Custom CSS hover transitions (card lifts, image scaling, glowing borders) that perform smoothly without JavaScript overhead.
- **Responsive Design**: Fully fluid layouts that gracefully degrade from desktop (3 columns) to tablet (2 columns) to mobile (1 column).
- **Inline Video Playback**: Custom-built JavaScript video player logic that pauses active videos when a new one is clicked.
- **Modal System**: Custom JavaScript modals for displaying resume details and PDF previews directly within the DOM.

---

## 🧱 Tech Stack

- **HTML5** – Semantic structure and responsive media handling
- **CSS3** – Advanced Grid/Flexbox layouts, variables, keyframe animations, pseudo-elements, and responsive media queries
- **JavaScript** – DOM manipulation, form validation, modal state management, and media playback control
- **FontAwesome** – Scalable vector icons for UI elements

## 💡 How to Use

1. **Clone or Download** this repository.
2. Open `index.html` in any modern web browser (no build step or server required).
3. Explore the various sections using the sticky navigation bar.
4. Interact with the project cards to see the hover effects, and click the video thumbnails to test the custom inline player.
5. Use the Resume menu to preview or download the PDF.
